🐾 OpenClaw MQ 对话测试

操作说明

① 启动环境

  1. 进入 mq.demo/ 目录
  2. 运行 docker compose up -d
  3. 等待 RabbitMQ 启动后执行：
    docker exec rabbitmq rabbitmq-plugins enable rabbitmq_web_stomp

② 连接 Broker

  1. 确认 WebSocket URL 为 ws://localhost:15674/ws
  2. 用户名 admin，密码 123456（与 docker-compose 一致）
  3. 点击「连接」按钮，状态变绿即成功

③ 发送消息

  1. 在底部输入框输入文字
  2. 按 Enter 或点击「发送」
  3. 消息发往 openclaw-in 队列
  4. OpenClaw Agent 的回复会自动出现在对话框

④ 消息流向

  • 发送：openclaw-in
  • 接收：openclaw-out
  • 消息头自动携带 x-sender-id 和 x-message-id
  • Sender ID 可在输入框左侧修改
⚠️ 前置条件： OpenClaw Gateway 需已启动并配置 RabbitMQ MQ channel（brokerUrl: amqp://admin:123456@localhost:5672， consumerTopic: openclaw-in，topic: openclaw-out）。 若连接失败，请确认 15674 端口已映射且 rabbitmq_web_stomp 插件已启用。
